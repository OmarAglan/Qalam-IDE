# حزم قلم المستقلة

## Windows

ينتج مثبت قلم المستقل الملف `qalam-setup-3.7.0-x64.exe` وملف SHA-256
المجاور له. يضم المثبت تطبيق قلم، مكتبات Qt المطابقة، وخادم Baa-LSP الداخلي
فقط. لا يضم باء أو تكوين أو نظم أو رابطا، ولا يضيف أي مجلد إلى `PATH`.

التثبيت الافتراضي لكل المستخدمين داخل `Program Files\Qalam`. يمكن استخدام
`/CURRENTUSER` للتثبيت بلا صلاحية المدير. يحافظ المثبت على `AppId` ثابت
للترقية والإصلاح والإزالة، ويجري فحصا داخليا لـBaa-LSP بعد نسخ الملفات.

### البناء

```powershell
.\scripts\build_installer.ps1 `
  -BuildDir build\windows-release `
  -BaaLspExecutable ..\Baa-LSP\build\windows-release\baa-lsp.exe
```

لإصدار Authenticode، أضف `-SignToolName releasesign` و
`-SignToolCommand '<signtool command using $f>'`. يوقع البناء المثبت وبرنامج
الإزالة ثم ينشئ ملف SHA-256 من البايتات الموقعة.

### التحقق

```powershell
.\scripts\test_installer.ps1
```

يتحقق الاختبار من الهضم، والتثبيت الصامت في مسار فيه مسافات، ووجود Qt
وBaa-LSP، وغياب الأدوات الخارجية، وعدم تغير `PATH`، وصحة اختصار قائمة
ابدأ وتشغيل نافذة قلم الأصلية من خلاله، ثم الإزالة الكاملة.

يكتشف قلم الأدوات الخارجية بالترتيب الموثق في دليل المستخدم. غياب أداة لا
يفسد تثبيت IDE؛ تعرض صفحة **الأدوات** حالتها والمسار المختار بوضوح، وتبقى
الكتابة وBaa-LSP عاملين بينما تتعطل عمليات البناء غير الممكنة مع سبب عربي
دقيق.

## Linux

تنتج حزمة Linux الملف `Qalam-3.7.0-x86_64.AppImage` وملف SHA-256 المجاور
له، وفق عقد مثبت Windows نفسه: قلم، ومكتبات Qt 6.10.2 ومكتبات xcb التي
يحتاجها مكوّن العرض، وخادم Baa-LSP الداخلي في `usr/bin/baa-lsp` فقط. لا تضم
الحزمة باء أو تكوين أو نظم أو رابطا، ولا تغيّر `PATH` ولا أي ملف خارجها.
تحمل الحزمة ملف سطح المكتب وأيقونات قلم وتعريفات أنواع ملفات باء ونظم
لأدوات الدمج مع سطح المكتب.

### البناء

```sh
./scripts/package-linux.sh   --build-dir build/linux-release   --baa-lsp ../Baa-LSP/build/baa-lsp   --qt-dir ~/Qt/6.10.2/gcc_64
```

أدوات التحزيم (linuxdeploy وإضافة Qt وappimagetool ووقت تشغيل AppImage)
مثبتة بإصدار وهضم SHA-256 ويُتحقق منها قبل تشغيلها.

### التحقق

```sh
./scripts/test-linux-appimage.sh dist/linux/Qalam-3.7.0-x86_64.AppImage
```

يشغّل CI الاختبار في حاوية Ubuntu 24.04 جديدة بلا Qt مع
`--install-desktop-baseline`، فلا تتوفر إلا مكتبات سطح مكتب أساسية. يتحقق
الاختبار من الهضم، ومحتويات الحزمة بعد فكها في مسار عربي فيه مسافات، وغياب
الأدوات الخارجية، وعدم وجود مكتبة غير محلولة، وأن Qt يُحمّل من داخل الحزمة،
ومصافحة `initialize` مع Baa-LSP الداخلي، ثم يفتح ملفا عربيا في قلم تحت Xvfb
فيتحقق من نافذة أصلية وتشغيل Baa-LSP الداخلي، وأن الخادم لا يبقى بعد إغلاق
قلم.
